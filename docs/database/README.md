## 사용자 인증과 즐겨찾기

- `users`: 정규화된 이메일과 PBKDF2-SHA256 비밀번호 해시를 저장합니다.
- `user_sessions`: 원문 세션 토큰 대신 SHA-256 해시와 만료 시각을 저장하며, 사용자 삭제 시 함께 삭제됩니다.
- `favorite_routes`: 사용자별 경로 검색 횟수를 저장합니다. `(user_id, origin, destination)`가 유일하므로 다른 사용자의 경로와 섞이지 않습니다.

`003_add_auth_and_user_favorites.sql`은 위 세 테이블을 기존 데이터 삭제 없이 추가합니다. 즐겨찾기 조회와 경로 검색 기록 API는 유효한 로그인 세션을 필수로 요구합니다.
