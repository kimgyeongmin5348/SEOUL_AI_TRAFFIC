# 학습 모델 기반 경로 추천

`POST /api/routes/predict`는 OSRM 경로 후보의 도로명과 구간 주행시간을 받아 저장된 베스트 모델로 교통량을 예측한다. GPS 좌표는 이 API에 전송하거나 DB에 저장하지 않는다.

## 모델 선택

`ml/artifacts/reports/*_report.csv` 및 기존 `ml/artifacts/ml_models/*_metrics.json`에서 실제 joblib 파일이 존재하는 모델을 비교한다. 동일한 검증 구간·행 수·분할 방식에서 RMSE 오름차순, 동률이면 R² 내림차순으로 선택한다. leaderboard의 채택되지 않은 학습 시도는 사용하지 않는다. 저장 파일 수정 시 모델 캐시를 갱신한다. 현재 저장 파일 기준 XGBoost `traffic_xgb_baseline_v1` (RMSE 174.7937)이 선택된다. 배포 환경에도 보고서와 해당 joblib 파일이 필요하다.

## 예측과 추천의 의미

학습 대상은 시간당 교통량이며 ETA가 아니다. 학습 당시 feature_columns 순서로 시간/요일, 지점 TM 좌표, 방향, 기상, 정확한 1·2·24시간 지연 및 이동평균을 생성한다. 방향별 연속 24시간 관측이 필요하다. VolInfo의 게시 지연은 최대 3시간까지만 동일 모델의 순차 예측으로 보완한다. 기상은 최대 36시간 이내 관측을 유지하는 가정이며 관측 시각을 표시한다. 그보다 오래된 데이터는 추천을 차단한다.

OSRM steps의 도로명과 관측지점의 도로명을 일치시켜 양방향 교통량을 합산한다. 이는 도로 단위 근사이며 방향·차선별 지도 매칭이나 회전 안내가 아니다. 각 구간의 전일 동시간 대비 예측 교통량 증가율을 0~2로 제한해 구간시간에 가중한다. 평가 점수 = OSRM 시간 × (1 + 시간 가중 증가율). 이는 학습된 주행시간이 아닌 추천 점수다. 화면 소요시간에는 OSRM 값을 그대로 사용한다.

모든 후보의 시간 기준 예측 반영 범위가 50% 이상일 때만 최소 점수 경로를 추천한다. 부족하거나 추론에 실패하면 AI 추천 없이 OSRM 기본 경로를 표시한다. 임의 경유지·가짜 경로·고정 지연·사고·날씨·절약시간은 생성하지 않는다.

## 검증

`python -m pytest backend/tests/unit -q`

저장 모델 선택, 실제 모델 추론, 예측값에 따른 추천 변경, 누락 범위 차단, 정확한 지연 특성, 지연 관측의 순차 예측, 오래된 관측 차단 및 API 입력 검증을 포함한다. 실제 이용 시 현재 시점까지 이어진 교통량과 기상 관측이 수집되어 있어야 한다.
